## Debugging

Documentación del proceso.

Inicie el proceso de debug con un click derecho y en la pestaña de debig, este proceso frena o corta el programa para cada linea donde hay una acción o una toma de inputs, cada que lo pauso me manda a una pestaña de System.java a un metodo llamado nanoTime().

Eso de lado no hay errores al haber o no archivo de guardado.
